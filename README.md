## 📂 Vorgestellte Projekte

Die folgenden Projekte spiegeln meine praktische Erfahrung in den Bereichen Full-Stack-Webentwicklung, objektorientierte Programmierung und Backend-Entwicklung wider:

1. **FlowLine**
   * **Beschreibung:** Eine robuste Full-Stack-Webanwendung zur strukturierten Verwaltung von Einträgen.
   * **Features:** Echtzeit-Suche, Benutzerauthentifizierung (Flask-Login), Mehrsprachigkeit (i18n), PDF-Export.
   * **Tech Stack:** Python, Flask, Jinja2, SQLite/PostgreSQL
   * **Live-Demo:** [Farzaneh-Soghani-FlowLine](https://farzaneh-soghani-flowline.onrender.com)

2. **Game (Java Konsolenspiel)**
   * **Beschreibung:** Ein interaktives Java-Konsolenspiel für zwei Spieler mit beweglichen Spielsteinen und objektorientierter Logik.
   * **Tech Stack:** Java 17, Object-Oriented Programming (OOP)
   * **Repository:** [GitHub Repository](https://github.com/farzaneh-soghani/Game)

3. **jobtracker-oop-cli**
   * **Beschreibung:** Eine objektorientierte Bewerbungsverwaltung mit integriertem Follow-up-System und professionellen CLI-Tabellen.
   * **Tech Stack:** Python 3.11+, OOP, JSON-Persistenz, python-dateutil, Rich CLI
   * **Repository:** [GitLab Repository](https://gitlab.com/farzanehsoghani/jobtracker-oop-cli)
